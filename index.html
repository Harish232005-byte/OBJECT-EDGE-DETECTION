Project Concepts & Algorithm Steps

Objective: Accurately identify and highlight object boundaries from 2D images.

Concepts Used: Edge detection, gradient operators, contour extraction, shape representation.

4-Step Execution Pipeline:

  1. 1. Convert Image to Grayscale: Eliminates chromatic noise and simplifies the pixel matrix from RGB into a 1-channel luminance map: \(Y = 0.299R + 0.587G + 0.114B\). Gaussian smoothing is applied to suppress high-frequency sensor noise.
  2. 2. Apply Sobel & Canny Edge Detection:
    • Sobel Operator: Convolves the image with horizontal (\(G_x\)) and vertical (\(G_y\)) derivative kernels to compute gradient magnitude \(\nabla I = \sqrt{G_x^2 + G_y^2}\).
    • Canny Edge Detector: Performs gradient computation, non-maximum suppression (thinning edges to 1-pixel width), and hysteresis thresholding (\(T_{\text{low}}, T_{\text{high}}\)) for optimal, connected edge curves.
    • Morphological Closing: Bridges microscopic edge gaps to guarantee sealed, watertight object boundaries ("Perfect Detection").
  3. 3. Extract Contours & Shape Representation: Uses topological border following to extract closed contour coordinates. Evaluates perimeter (\(L\)), area (\(A\)), circularity (\(4\pi A / L^2\)), Douglas-Peucker polygon vertices, and image moments for shape classification (Circle, Triangle, Rectangle, Square, Polygon).
  4. 4. Draw Object Boundaries: Renders boundary contours with customizable colors, line thicknesses, bounding boxes, centroid pins, and classification tags.
